# X Likes Shortcut

X (Twitter) の左サイドバーに「いいね」へのショートカットを追加し、不要な項目を隠せる Chrome 拡張機能(Manifest V3)。

## 機能

- サイドバーの「履歴」(ブックマーク)の下に「いいね」を追加。押すと `/<自分のID>/likes` を開く
- 左サイドバーの各項目(ホーム、通知、Grok、プレミアム など)を、拡張機能のポップアップから個別に表示/非表示
- 設定は `chrome.storage.sync` に保存され、X のタブへ即時反映

初期状態では「通話」「クリエイタースタジオ」「プレミアム」を隠します。

## インストール

1. `chrome://extensions` を開き、「デベロッパー モード」を ON
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
3. x.com を再読み込み

## 構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の定義 |
| `items.js` | サイドバー項目と対象セレクタの定義(popup / content で共有) |
| `content.js` | 「いいね」項目の挿入、非表示設定の適用 |
| `popup.html` / `popup.js` | 表示切り替え UI |

## メンテナンス

X の画面構造に依存しています。項目が出ない・隠れない場合は `items.js` のセレクタを更新してください。
項目の追加は `XLS_ITEMS` に1行足すだけです。
